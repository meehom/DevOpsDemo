## 背景

项目需要一组最小的可演示功能，用来验证 CI/CD 流水线（单测、端到端测试、镜像发布）是否完整可用。
同时需要一个真实可点击的页面，让端到端测试有稳定的操作目标，而不是去点 Swagger UI 这种结构易变的内置页面。

## 目标

提供一个两数相加的接口，以及一个能在浏览器里输入两个数、点击按钮看到结果的页面。
页面结果必须与接口返回一致。

## 验收标准

- [x] AC-1: 调用 `GET /add?a=2&b=3` 返回 `{"result": 5.0}`
- [x] AC-2: 调用 `GET /add?a=1.5&b=-0.5` 返回 `{"result": 1.0}`
- [x] AC-3: 缺少参数时返回 422
- [x] AC-4: `GET /ui` 返回 200，页面标题为「两数相加」
- [x] AC-5: 页面输入 2 和 3 点击「计算」后，结果区域显示 `5`
- [x] AC-6: 页面上展示的结果与后端接口返回一致（1.5 + -0.5 显示 `1`）
- [x] AC-7: `GET /health` 返回 `{"status": "ok"}`，供容器健康检查使用

## 非目标

- 不做计算历史、不做用户输入校验之外的表单限制
- 不做前端框架引入，页面保持单文件内联实现
- 不做多语言

## 影响范围

- 新增接口: `GET /add`、`GET /health`
- 新增页面: `GET /ui`
- 相关文件: `app/main.py`、`app/ui.py`

## 测试映射

- 单元测试: `tests/test_req_001_add_api.py`
- 端到端测试: `tests/e2e/test_req_001_ui.py`
