## 设计目标

给家长演示用的择校筛选界面。目标不是好看，而是**让客户在没有账号、没有真实数据的情况下点得动**，
一次演示就能对齐三件事：

1. 有哪些筛选维度（行政区、办学性质）
2. 筛选结果长什么样、一屏能放多少所院校
3. 「加入目标清单」这个动作怎么反馈、怎么回看

视觉令牌**完全沿用 [DS-001](../DS-001-演示应用高保真/design.md)**，不新开一套配色。

## 页面与路由

| 页面 | 路由 | 关键内容 | 跳转 |
|---|---|---|---|
| 目标院校筛选 | `/ui/schools` | 顶部应用栏 + 筛选区 + 结果列表 | 无 |

页面是单页，筛选条件变化时原地重渲染结果列表，不跳路由、不带路由参数。

## 筛选器结构

筛选区自上而下三块，横向排列在桌面端、纵向堆叠在移动端：

| 区块 | 组件 | 取值 | 行为 |
|---|---|---|---|
| 行政区 | Filter Chip 多选组（16 枚，可换行） | 徐汇 / 黄浦 / 浦东 / 静安 / 杨浦 / 闵行 / 普陀 / 虹口 / 长宁 / 宝山 / 嘉定 / 松江 / 青浦 / 奉贤 / 金山 / 崇明 | 可多选，选中为「或」关系；一个都不选等于全选 |
| 办学性质 | Filter Chip 单选组（3 枚） | 全部 / 公办 / 民办 | 互斥；「全部」等于不加该条件 |
| 目标清单开关 | Switch + 文字「只看目标清单」 | 开 / 关 | 开启后仅在结果中保留已加入目标清单的院校 |

筛选区右侧（移动端为下方）放一个 Text Button「重置」，清空以上三个条件。

结果计数固定显示在筛选区上方：「共 N 所」，N 为当前结果数。

## 结果列表

每所院校一张 Elevated Card，横向排布：

- 左侧：圆形图标容器，内放校名首字（Material 3 头像样式，底色 primaryContainer）
- 中部：校名（主标题，16sp/600）；下方一行次要说明「行政区 · 办学性质」（12sp/400，onSurfaceVariant）
- 右侧：目标清单图标按钮。未加入时为描边星形，加入后为实心星形且容器变 primaryContainer

桌面端卡片单列通栏，移动端同样单列。

空态：结果数为 0 时，列表区居中显示搜索无结果图标与文案「没有符合条件的院校」，并提示可点「重置」。

## 设计令牌

沿用 DS-001 的全部颜色角色（primary / onPrimary / primaryContainer / onPrimaryContainer /
secondaryContainer / surface / surfaceContainer / onSurface / onSurfaceVariant / outline / surfaceTint / error），
不新增、不改值，组件内一律按角色名引用。

本设计新增的两个用色约定：

| 用途 | 角色 |
|---|---|
| 筛选 Chip 选中态底色 / 文字 | primaryContainer / onPrimaryContainer |
| 筛选 Chip 未选中态描边 / 文字 | outline / onSurfaceVariant |

形状：卡片 16dp、Chip 全圆角（999dp）、图标按钮圆形。
字体：系统字体栈，不引外链字体。
断点：≥900px 筛选区横排；<900px 筛选区纵向堆叠，行政区 Chip 横向滚动。

## 交互契约

| 触发 | 目标 | 说明 |
|---|---|---|
| 点击行政区 Chip | 原地刷新结果列表 | 多选切换，结果计数同步更新 |
| 点击办学性质 Chip | 原地刷新结果列表 | 单选互斥 |
| 切换「只看目标清单」 | 原地刷新结果列表 | 布尔开关 |
| 点击「重置」 | 清空三个条件并刷新 | 刷新后结果等于全量 |
| 点击卡片右侧星形按钮 | 切换该院校目标状态 | 图标与底色立即切换，同时写回后端 |
| 筛选结果为空 | 空态区域 | 显示「没有符合条件的院校」 |

## 数据说明

**mockup.html 里全部为虚构数据**，写死在页面脚本里，不请求任何后端接口，页面顶部常驻
「演示原型 · 数据均为虚构，不代表真实招生信息」提示条。

正式实现时数据由 `GET /schools` 提供，筛选在服务端完成，页面只负责渲染；院校名与行政区分布
仍为演示用虚构数据，不代表任何真实学校的招生信息。
