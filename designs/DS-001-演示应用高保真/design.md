## 设计目标

给客户演示用的第一版界面。目标不是好看，而是**让客户在没有任何后端、没有任何账号的情况下点得动**，
一次演示就能对齐「有哪些页面、每页放什么、点了会怎样」。

## 页面与路由

| 页面 | 入口 | 关键内容 | 跳转 |
|---|---|---|---|
| 概览 | 侧边导航/底部导航第 1 项 | 3 张统计卡、最近商品列表 | 点商品 → 提示条 |
| 商品 | 第 2 项 | 商品卡片网格、右下悬浮按钮 | FAB → 新增商品对话框 |
| 计算器 | 第 3 项 | 两个数字输入框、计算按钮、结果区 | 无 |

## 设计令牌

Material 3 颜色角色（浅色主题），实现时必须按角色名引用，不要写死十六进制值：

| 角色 | 值 | 用途 |
|---|---|---|
| primary | #00696E | 主按钮、选中态 |
| onPrimary | #FFFFFF | 主色上的文字 |
| primaryContainer | #9CF1F6 | 选中项底色、FAB 容器 |
| onPrimaryContainer | #002022 | primaryContainer 上的文字 |
| secondaryContainer | #CCE8E9 | 次级标签片 |
| surface | #F4FBFB | 页面底色 |
| surfaceContainer | #E8EFF0 | 卡片、导航栏 |
| onSurface | #161D1D | 正文 |
| onSurfaceVariant | #3F4949 | 次要文字 |
| outline | #6F7979 | 描边、分隔线 |
| surfaceTint | #00696E | 海拔叠加色 |
| error | #BA1A1A | 错误态、负值 |

形状：卡片 16dp、对话框 28dp、按钮全圆角。
字体：系统字体栈（不引外链字体，客户断网也要能看）。
断点：≥900px 用侧边导航栏（rail），<900px 用底部导航栏。

## 交互契约

| 触发 | 目标 | 说明 |
|---|---|---|
| 点击导航项 | 同页切换视图 | 无路由参数 |
| 点击商品卡片 | 底部提示条 | 显示「已选择：<商品名>」 |
| 点击 FAB | 新增商品对话框 | 表单填名称与价格，确认后插入列表首位 |
| 点击计算按钮 | 结果区 | 本地计算 a + b，不请求后端 |

## 交付说明

- `mockup.html`：全假数据、纯静态、零外部依赖，双击即可演示，**这就是交给客户的文件**
- `prompt.md`：设计提示词，用于生成 mockup 和后续前端实现
- `shots/`：桌面端与移动端的界面截图
